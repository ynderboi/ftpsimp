# Инструкция ftpsimp

> **Язык / Language:** Русский | [English](https://github.com/ynderboi/ftpsimp/blob/master/docs/GUIDE.en.md)

Обмен файлами по Wi‑Fi в локальной сети: на компьютере или телефоне запускается мини‑сервер, а на другом устройстве открывается браузерный проводник в стиле Windows 98.

Актуальный Windows‑релиз: **1.1.2** (`ftpsimp-setup-1.1.2.exe`).  
Актуальный Android‑релиз: **1.1.1** (`ftpsimp-1.1.1.apk`).

## Что нужно

- Хост и клиент в **одной Wi‑Fi / LAN** сети
- На клиенте обычный браузер (Chrome, Safari, Firefox и т.д.)
- Порт по умолчанию: **8080** (не должен быть занят)

Не выставляйте порт ftpsimp в интернет (проброс портов / VPS) — это LAN‑инструмент.

## Windows — установка и запуск

### Установка

1. Скачайте **`ftpsimp-setup-1.1.2.exe`** из [релизов](https://github.com/ynderboi/ftpsimp/releases).
2. Запустите установщик (русский / English).
3. При желании поставьте галочку «Ярлык на рабочем столе».
4. После установки запустите **ftpsimp** из меню Пуск.

### Первый запуск

1. Откроется консольное окно с большим логотипом **FTPSIMP** и панелью статуса.
2. Найдите строку **PIN** (обычно 6 цифр) и адрес вида `http://192.168.x.x:8080`.
3. На телефоне / другом ПК в той же сети откройте этот адрес в браузере.
4. Введите PIN → откроется проводник с файлами.

### Флаги запуска (опционально)

Если запускаете `ftpsimp.exe` вручную:

| Флаг | Назначение |
|------|------------|
| `-port 8080` | HTTP‑порт |
| `-dir "C:\path"` | Папка для шаринга |
| `-pin 123456` | Фиксированный PIN |
| `-readonly` | Только просмотр и скачивание |
| `-open` | Без PIN (только в доверенной сети!) |
| `-plain` | Простой лог без интерактивной панели |

Настройки сохраняются в `%AppData%\ftpsimp\config.json`.

## Панель управления в консоли (TUI)

После старта в терминале доступны горячие клавиши:

| Клавиша | Действие |
|---------|----------|
| **S** / Пробел | **Start / Stop** HTTP‑сервера (без выхода из программы) |
| **1** | Сменить корневую папку |
| **2** | Включить / выключить read‑only |
| **3** | Включить / выключить PIN‑авторизацию |
| **4** | Сгенерировать новый PIN (старые сессии сбрасываются) |
| **5** | Задать PIN вручную |
| **6** | Обновить список LAN‑адресов |
| **Q** | Выйти из приложения (спросит подтверждение Y/N) |

В панели видно: STATUS (RUNNING/STOPPED), ROOT, PORT, MODE, AUTH, PIN, SESSIONS, URL.

## Веб‑проводник

Интерфейс в стиле Windows 98.

### Вход

- Если auth включён — окно **Log On** с полем PIN.
- PIN смотрите на хосте (консоль Windows или экран Android‑приложения).
- На телефоне окно входа остаётся компактным диалогом; поле PIN рассчитано на цифровую клавиатуру.

### Возможности

- Просмотр папок, скачивание файлов
- Загрузка (кнопка / drag‑and‑drop), создание папок, удаление
- **Обновить** (меню или кнопка ↻) — актуальное содержимое папки
- Поле **Адрес** — реальный путь на диске хоста
- Язык: **Рус / Eng** (в меню и в трее)
- Окна можно двигать, растягивать, сворачивать / разворачивать
- **Настройки** → смена корневой папки: **только с хоста** (с телефона путь сменить нельзя)

### Read‑only

Если на хосте включён режим только чтения:

- Скачивание работает
- При попытке загрузить файл или создать папку появится предупреждение

## Android

### Установка APK

1. Скачайте **`ftpsimp-1.1.1.apk`** из [релизов](https://github.com/ynderboi/ftpsimp/releases).
2. На телефоне разрешите установку из неизвестных источников (для браузера / файлового менеджера).
3. Установите APK и откройте **ftpsimp**.

### Использование

1. Выберите папку для шаринга (или используйте папку по умолчанию).
2. Нажмите **Запустить сервер**.
3. На экране появятся:
   - адреса `http://…:8080`
   - **PIN** для входа с другого устройства
4. На втором устройстве откройте адрес в браузере и введите PIN.
5. Чтобы остановить — нажмите **Остановить** (или через уведомление).

Смена корневой папки на Android — **только в приложении**, не через веб‑настройки.

## Безопасность

| Механизм | Поведение |
|----------|-----------|
| PIN + сессия | Без PIN API закрыт (кроме login/status) |
| Смена root | Только с хоста |
| Read‑only | Запрет upload / mkdir / delete |
| `-open` / Auth OFF | Любой в LAN имеет полный доступ — только для доверенной сети |
| HTTP | Трафик не шифруется — рассчитано на домашнюю LAN |

Рекомендации:

- Держите **Auth ON**
- Не используйте `-open` в общественном Wi‑Fi
- Не пробрасывайте порт наружу

## Типичные проблемы

**Не открывается адрес с телефона**  
Проверьте одну Wi‑Fi сеть, что сервер RUNNING, Windows Firewall не блокирует порт 8080, адрес актуальный (клавиша **6** в TUI).

**Неверный PIN**  
Смотрите актуальный PIN на хосте. После **Rotate PIN (4)** старые сессии недействительны.

**Поле PIN на телефоне ведёт себя странно**  
Обновите хост до **1.1.2+** и сделайте жёсткое обновление страницы в браузере. Окно входа не должно растягиваться на весь экран.

**Не меняется корневая папка из браузера**  
Откройте UI на самом хосте (localhost / LAN‑IP этой машины) или смените путь в TUI (**1**) / в Android‑приложении.

**Порт занят**  
Запустите с другим портом: `ftpsimp.exe -port 8081`.

**На Android «сначала выберите папку»**  
Выберите доступную папку через кнопку выбора и снова запустите сервер.
